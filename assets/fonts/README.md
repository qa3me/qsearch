# Qsearch fonts

Qsearch uses **Tahrir Bold** for Persian display headings and **Farhang2 Regular/DemiBold** for body text and numerals. Segoe UI and Tahoma are the public-build fallbacks.

Purchased binaries belong in `assets/private/fonts/`, which is intentionally ignored by git. A local build conditionally copies them into the application. Do not commit or publish those files.

Both supplied licenses require the purchaser's six-digit license code in the accompanying license text before redistribution. Public release packaging must keep the private-font condition disabled until that code has been supplied and verified.
