# Font Awesome Free attribution

Qsearch vendors the path geometry for these nine icons from Font Awesome Free 7.3.1:

- `folder` (Solid)
- `file` (Solid)
- `window-maximize` (Solid), used for application files
- `shield-halved` (Solid), used for local file review
- `xmark` (Solid)
- `arrow-up-right-from-square` (Solid)
- `gear` (Solid)
- `circle-info` (Solid)
- `github` (Brands)

Sources:

- https://github.com/FortAwesome/Font-Awesome/tree/7.3.1/svgs/solid
- https://github.com/FortAwesome/Font-Awesome/tree/7.3.1/svgs/brands
