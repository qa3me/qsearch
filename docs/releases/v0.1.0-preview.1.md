# Qsearch v0.1.0-preview.1

Qsearch is a fast, Windows-native, fully offline file search app with English
and Persian interfaces, local metadata preview, tray/launcher access, and
cautious non-destructive file-review signals.

> **Unsigned preview:** This prerelease is intended for evaluation. Windows
> may show an unknown-publisher or SmartScreen warning. Verify the adjacent
> SHA-256 file before running it.

## Highlights

- Fast sortable local search with Persian/Arabic normalization and filters.
- Personal-folder indexing without administrator access.
- Optional read-only elevated helper for whole-PC fixed NTFS indexing.
- Full, compact, and centered launcher surfaces with light/dark/system themes.
- Local preview, metadata, default-app details, and open/reveal actions.
- Explainable local file-review signals with no quarantine or automatic action.
- No account, telemetry, cloud lookup, update check, or runtime data transfer.

## Downloads

- **Portable:** includes the .NET runtime; extract and run `Qsearch.exe`.
- **Slim:** smaller download; requires .NET 10 Desktop Runtime for Windows x64.

Each ZIP has an adjacent `.sha256` file. No installer is included.

## Known limitations

- Executables are not digitally signed.
- The complete physical-device, scaling, accessibility, and UAC matrix is not
  yet complete.
- The compact surface is a native companion window, not a Windows Widgets
  Board provider.
- File review provides cautious signals and **does not determine whether a
  file is safe or malicious**.

# کیوسرچ v0.1.0-preview.1

Qsearch یک برنامهٔ بومی ویندوز برای جست‌وجوی سریع و کاملاً آفلاین فایل‌هاست؛
با رابط فارسی و انگلیسی، پیش‌نمایش و فرادادهٔ محلی، دسترسی از tray و لانچر،
و نشانه‌های محتاطانه و غیرمخرب برای بررسی فایل.

> **نسخهٔ آزمایشی بدون امضا:** این پیش‌انتشار برای ارزیابی است. ممکن است
> ویندوز هشدار ناشر ناشناخته یا SmartScreen نشان دهد. پیش از اجرا، فایل
> SHA-256 کنار بسته را بررسی کنید.

## قابلیت‌های اصلی

- جست‌وجوی محلی سریع و مرتب‌شدنی با یکسان‌سازی حروف فارسی/عربی و فیلترها.
- فهرست‌سازی پوشه‌های شخصی بدون نیاز به دسترسی مدیر.
- helper فقط‌خواندنی و اختیاری برای فهرست سریع دیسک‌های ثابت NTFS.
- پنجرهٔ کامل، حالت جمع‌وجور و لانچر مرکزی با تم روشن، تیره و هماهنگ با سیستم.
- پیش‌نمایش، فراداده، برنامهٔ پیش‌فرض و دکمه‌های بازکردن فایل/مسیر.
- نشانه‌های قابل توضیح بررسی فایل، بدون قرنطینه یا اقدام خودکار.
- بدون حساب کاربری، تله‌متری، سرویس ابری، بررسی آپدیت یا انتقال داده در زمان اجرا.

## فایل‌های دریافت

- **Portable:** دارای Runtime؛ فایل ZIP را استخراج و `Qsearch.exe` را اجرا کنید.
- **Slim:** کم‌حجم‌تر؛ نیازمند .NET 10 Desktop Runtime برای Windows x64.

کنار هر ZIP یک فایل `.sha256` قرار دارد. در این نسخه installer ارائه نمی‌شود.

## محدودیت‌های شناخته‌شده

- فایل‌های اجرایی امضای دیجیتال ندارند.
- ماتریس کامل دستگاه واقعی، مقیاس نمایش، دسترس‌پذیری و حالت‌های UAC هنوز کامل
  نشده است.
- حالت جمع‌وجور یک پنجرهٔ بومی همراه است، نه Windows Widgets Board.
- بررسی فایل فقط نشانه‌های محتاطانه می‌دهد و **حکم قطعی دربارهٔ سالم یا مخرب
  بودن فایل نیست**.
