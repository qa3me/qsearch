# Code of conduct

Qsearch contributors are expected to keep project spaces respectful, focused, and safe.

- Be considerate of different backgrounds, languages, experience levels, and accessibility needs.
- Critique ideas and code, not people.
- Do not publish private information, file paths, security reports, or personal data without permission.
- Avoid harassment, threats, discriminatory language, sexualized conduct, and sustained disruption.
- Report serious conduct concerns privately to `contact@qa3.me`.

Maintainers may edit or remove contributions and restrict participation when behavior harms the project or its community. Enforcement decisions should be proportionate, documented privately, and avoid unnecessary disclosure.
