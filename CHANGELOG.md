# Changelog

All notable changes are documented here. The project follows semantic versioning once public releases begin.

## 0.1.0-preview.1 - 2026-11-16

### Added

- Native bilingual WPF search interface and compact companion window.
- Transactional SQLite/FTS index with Persian/Arabic normalization.
- Standard-user folder crawl, NTFS journal infrastructure, and a bounded elevated helper.
- Explainable, local, non-destructive file review.
- Tray, global shortcut, single-instance activation, benchmark harness, privacy gates, and deterministic portable packaging.
- Dark, light, and system-aware themes with English and Persian layouts.
- Portable and Slim Windows x64 preview packages with SHA-256 checksums and bundled license notices.

### Known limitations

- This preview is unsigned; Windows may show an unknown-publisher warning.
- The complete physical-device, scaling, accessibility, and alternate-administrator UAC matrix remains pending.
- The compact surface is a native companion window rather than a Windows Widgets Board provider.
- No installer is included in this preview. Use either extracted ZIP package.
